## Графические последовательности степеней

**Контекст.** В `../00-lib-example.py` вызов `nx.random_degree_sequence_graph([1, 1, 1])` падает с `NetworkXUnfeasible: degree sequence is not graphical`.

**Что разобрать позже**

- Что значит «последовательность степеней графическая» (существует простой неориентированный граф с такими степенями).
- Необходимые условия: диапазон \(0 \le d_i \le n-1\), лемма о рукопожатиях (сумма степеней чётна).
- Критерий Хавела–Хакими (пошаговое сведение списка).
- Теорема Эрдёша–Галлаи (неравенства по префиксам).
- Почему `[1, 1, 1]` не графическая и как подобрать валидный список для примера в NetworkX (`nx.is_graphical`).
