## Частные производные и градиент

* частные производные
* определение частной производной через предел
* геометрический смысл частной производной
* локальная линейная аппроксимация 
* достаточная гладкость и свойство симметрии
* Для вычисления частной производной по выбранной переменной дифференцируем функцию по этой переменной, рассматривая все остальные переменные, как константы.
* Даже когда переменная объявлена константой для дифференцирования, она может участвовать в выражении. Цепное правило - основной инструмент для работы со сложными функциями при вычислении частных производных.
* Наличие частных производных не гарантирует дифференцируемость - вана согласованность изменения функции по всем направлениям.
* локальная чувствительность
* безразмерная эластичность
* локальная интерпретация
* градиент и его геометрический смысл: градиент указывает направление наискорейшего роста, а его норма на величину максимальной направленной производной
* неравенство Коши - Буняковского
* Правило цепочки
* Якобиан
